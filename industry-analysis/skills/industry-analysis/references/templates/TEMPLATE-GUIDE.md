# 行业模板创作指南

> 如何为产业洞察 SOP 创建新的行业模板。

---

## 模板文件规范

### 文件位置

```
references/templates/<industry-slug>.md
```

### 命名规则

使用英文小写 + 连字符，如 `frontier.md`、`bio-tech.md`。

### 文件头注释

每个模板文件必须以注释开头，说明适用场景：

```markdown
# XXX 分析模板

> 当 `industry-analysis` 将行业类型判断为"XXX"时加载此模板。
> 适用场景：什么类型的行业用此模板分析。
```

---

## 必需章节（Must Have）

每个模板必须包含以下 6 个章节：

### 1. 核心框架

行业最核心的分析框架图（ASCII 图或表格形式）。例如：
- 制造业：上中下游产业链
- 软件：四层生态链
- 生物医药：管线驱动金字塔
- 能源：政策-技术-资本三角

### 2. 稀缺性控制点

表格形式，列出 4-6 个关键控制点及其稀缺性评级：

```markdown
| 控制点 | 稀缺性 | 说明 |
|--------|-------|------|
| **名称** | 🔴 极高 / 🟡 中高 / 🟢 中低 | 为什么稀缺 |
```

### 3. 超前指标方向

按类别列出该行业的超前指标：

```markdown
| 类别 | 具体指标示例 | 数据来源 |
|------|-------------|---------|
```

### 4. 竞争分析框架

- 市场集中度判断方法
- 主要玩家分析维度
- 进入壁垒分析

### 5. 市场规模估算

已商业化和未商业化两种情况的估算方法。

### 6. MCP 增强数据采集（可选）

该行业可用的 bio-research MCP 工具和采集策略。如果 MCP 不适用，注明"以 WebSearch 为主"。

---

## 可选章节（Nice to Have）

| 章节 | 适用场景 | 示例 |
|------|---------|------|
| **技术路线分析** | 多技术路线并行 | 前沿技术 → 多路线矩阵 |
| **监管路径** | 受监管行业 | 生物医药 → FDA/EMA |
| **政策分析** | 政策敏感行业 | 能源 → 碳价/补贴 |
| **开源/闭源** | 软件行业 | 软件模板 |
| **专利分析** | IP 密集型行业 | 生物医药 |
| **地缘竞争** | 地缘敏感行业 | 前沿技术、能源 |

---

## 验证清单

提交模板前确认：

- [ ] 有清晰的核心框架图/表
- [ ] 稀缺性控制点表格完整
- [ ] 超前指标不少于 6 项，覆盖 3+ 类别
- [ ] 竞争分析有明确的分析维度
- [ ] 市场规模估算方法明确
- [ ] MCP 注释注明适用工具（或无）
- [ ] 引用至少 1 个参考案例（如果有）

---

## 案例要求（For Examples）

当为模板添加验证案例时：

```
references/examples/<topic-slug>.md
```

案例结构：
1. **元数据**：行业、类型、分析日期、模式
2. **核心结论**：一句话判断
3. **关键发现**：3-5 条最有价值的洞察
4. **使用到的 SOP 步骤**：哪些步骤最有价值
5. **反思**：SOP 改进建议
