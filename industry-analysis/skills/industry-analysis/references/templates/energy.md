# 能源/清洁技术分析模板

> 当 `industry-analysis` 将行业类型判断为"能源/清洁技术"时加载此模板。
> 适用场景：可再生能源、储能、电网技术、电动汽车基础设施、碳管理、氢能等。

## 核心框架：政策-技术-资本三角

能源行业的最核心驱动力与传统制造或软件不同——政策和资本配置往往先于技术成熟度。

```
        🏛️ 政策（补贴/碳价/标准）
        /         \
       /           \
    🔬 技术 ←──→ 💰 资本
   (成本曲线)    (项目融资/投资)
```

| 维度 | 分析要点 | 关键信号 |
|------|---------|---------|
| **🏛️ 政策** | 补贴退坡时间表、碳价走势、可再生能源配额、排放标准 | 政策立法进展、碳价趋势、补贴调整公告 |
| **🔬 技术** | 成本下降曲线（学习率）、效率提升、技术路线收敛/发散 | LCOE/LOS 变化、效率纪录突破、专利趋势 |
| **💰 资本** | 项目融资规模、绿债发行、企业可再生能源采购(PPA)、VC/PE 流向 | 年度清洁能源投资额、PPA 签约量、融资成本 |

## 技术成本曲线分析（学习率）

能源行业最有效的分析工具之一是学习率（Learning Rate）——累计产量每翻一倍，成本下降的百分比。

```
成本$ ┊
      ┊   ↘ 学习率 = 20% 意味着
      ┊     ↘ 累计装机翻倍 → 成本降20%
      ┊       ↘
      ┊         ↘
      ┊           ↘
      └────────────────── 累计装机量
```

| 技术 | 典型学习率 | 当前成本 | 预测拐点 | 平价条件 |
|------|----------|---------|---------|---------|
| 光伏 | 20-25% | $/W | 已平价 | 低于煤电 LCOE |
| 风电 | 10-15% | $/W | 已平价 | 低于煤电 LCOE |
| 锂电池 | 15-20% | $/kWh | $100/kWh = 电动车平价 | 低于 ICE 总拥有成本 |
| 绿氢 | 10-15% | $/kg | $2/kg = 灰氢平价 | 低于天然气制氢 |
| 碳捕获 | 5-10% | $/tCO2 | $50-100/t | 碳价高于捕获成本 |

**关键问题：** 技术在成本曲线上处于什么位置？斜率是否在变陡（加速）还是变平（瓶颈）？

## 政策驱动分析

### 政策工具类型

| 工具 | 机制 | 影响方向 |
|------|------|---------|
| **补贴/税收优惠** (ITC/PTC) | 降低前期投资成本 | 短期需求拉动 |
| **碳定价** (ETS/碳税) | 提高化石能源成本 | 长期竞争力重塑 |
| **可再生能源配额** (RPS) | 强制一定比例绿电 | 保障性需求 |
| **排放标准** (CAFE/EU7) | 淘汰低效技术 | 技术路线锁定 |
| **碳边境调节** (CBAM) | 进口商品碳成本 | 贸易格局重塑 |

### 政策风险分析

```
政策支持 ┊
    ↑    ┊   🟢 成长期    🟡 成熟期
   强    ┊   (高补贴、     (补贴退坡、
         ┊    高增速)       标准驱动)
         ┊
   弱    ┊   🟡 萌芽期    🔴 衰退期
         ┊   (政策不确    (无政策支持、
         ┊    定性高)       被替代)
         └──────────────────────────→ 时间
```

**关键判断：** 政策是该行业的核心变量。分析时必须回答：政策支持是否可持续？退坡时间表如何？政策变化对行业利润的影响有多大？

## 项目融资与资本密集度

能源项目通常是重资产、长周期、低毛利——与传统制造不同。

| 指标 | 说明 | 分析要点 |
|------|------|---------|
| **CAPEX/W 或 CAPEX/kWh** | 每瓦或每度电的投资成本 | 资本密集度决定进入门槛 |
| **融资成本 (WACC)** | 项目贷款利率 + 股权回报 | 融资成本变化直接影响项目 IRR |
| **PPA 价格** | 购电协议锁定价格 | 长期合同锁定收入的水平 |
| **项目 IRR** | 内部收益率 | 通常 6-12%，受政策影响大 |

**"卖铲人"分析在能源行业的体现：**
- 即使运营商的电站项目 IRR 不高，上游设备供应商（逆变器/风机/电池制造）可能利润丰厚
- 项目开发商（开发商/EPC）赚的是整合和周转率，而非技术溢价

## 稀缺性控制点

| 控制点 | 稀缺性 | 说明 |
|--------|-------|------|
| **⛏️ 关键材料** | 🔴 极高 | 锂、钴、稀土、铜——能源转型的"石油" |
| **🔋 核心制造** | 🟡 中高 | 电池、逆变器、风机——集中度高 |
| **🔌 电网接入** | 🔴 极高 | 排队并网的时间和容量是最关键的瓶颈 |
| **📜 项目许可** | 🔴 极高 | 环保审批、土地使用——常延迟 3-7 年 |
| **💰 融资能力** | 🟡 中 | 低成本融资是核心竞争力 |
| **🏢 品牌/渠道** | 🟢 低 | 能源多为大宗商品，品牌溢价有限 |

## 竞争分析

- **市场集中度：** 光伏制造 → 高度集中在中国；风电 → 中国 + Vestas/Siemens
- **垂直整合 vs 专业化：** 能源行业两种路径都有
- **地缘竞争：** 清洁技术供应链的地缘政治化——IRA（美国）vs 欧洲绿色协议 vs 中国主导

## 市场规模估算

能源行业市场规模估算通常从**装机容量 × 价格**出发：

```
TAM = 年度新增装机(GW) × 系统价格($/W)
   + 运营维护(O&M)市场
   + 电力市场交易价值
   + 碳信用/碳移除市场
```

对于未商业化技术（如绿氢、碳捕获）：
```
潜在市场 = 政策驱动的需求下限 × 碳价情景
```
