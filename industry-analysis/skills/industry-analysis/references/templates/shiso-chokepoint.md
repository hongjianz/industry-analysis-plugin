# 紫苏叶卡点分析模块（Shiso Chokepoint Analysis）

> **核心问题：行业的真正稀缺性控制点在哪里？**
>
> 传统供应链分析回答"谁控制了什么零件"；紫苏叶卡点分析回答 **"什么物理/生物/制度/经济约束是所有玩家都绕不开的？"** ——以及 **"谁坐在这些约束上？"**

---

## 方法论来源

本模块提炼自对 CGM（连续血糖监测）行业的深度卡点分析实践。该方法融合了两种思维模式：

| 思维模式 | 回答的问题 | 工具 |
|---------|-----------|------|
| **传统供应链逐支下钻** | 谁控制了什么零件/环节？ | 分支分解 + 收手裁决 |
| **第一性原理分解** | 什么根本约束是换供应商也绕不开的？ | Ground Truth 识别 + 交叉效应 |

当两者结合时，能找到**比任何供应商瓶颈都更牢固的卡点**——因为物理定律和生物机制没有"替代供应商"。

---

## 六步执行流程

```
Step 1: 终端需求锁定        ← 什么需求在驱动行业？确定性多高？
Step 2: 供应链逐支下钻      ← 拆到几层后散掉？哪一支收手？
Step 3: 第一性原理分解      ← Ground Truth 是什么？哪些约束是物理/生物/制度必然？
Step 4: 交叉效应 + 重评估   ← GT 之间如何互相放大？修订供应链结论
Step 5: 强制反证            ← 如果不是卡点，世界应该什么样？
Step 6: "谁坐在卡点上"      ← 映射公司/机构到每个卡点位置
```

---

## Step 1: 终端需求锁定

在拆供应链之前，先确认**需求本身的确定性**。

### 需求陈述

用一句话描述：**[谁]需要[什么]，因为[什么根本原因]。**

### 确定性判断框架

| 需求维度 | 确定性 | 判断标准 |
|---------|--------|---------|
| 核心功能需求 | 高/中/低 | 是否存在非此不可的使用场景？ |
| 替代逻辑 | 高/中/低 | 新技术对旧技术是否存在数量级差异？ |
| 渗透率上限 | 中/低 | 是否受政策/成本/基础设施制约？ |
| 下沉市场 | 中-低 | 成本降低后是否自然扩大用户群？ |

**关键挂账（IF）：** 识别一个可能改变需求规模的假设条件。挂账条件变化时，需求规模重估。

---

## Step 2: 供应链逐支下钻

### 全景棋盘

先把终端产品拆成若干**支（Branch）**，每个支是一个独立的功能模块或价值环节。

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│  支 1    │  支 2    │  支 3    │  ...     │  支 N    │
│  (模块)  │  (模块)  │  (模块)  │          │          │
├──────────┼──────────┼──────────┼──────────┼──────────┤
│ • 子件A  │ • 子件B  │ • 子件C  │          │          │
│ • 子件D  │ • ...    │          │          │          │
└──────────┴──────────┴──────────┴──────────┴──────────┘
```

### 逐支下钻 + 四维证据表

对每个支，逐层下钻到下一级子件，每层使用 **四维证据表** 评估：

| 维度 | 问题 | 标记 |
|------|------|------|
| **主导供应商** | 供应是否有收敛？是否有单一/双寡头供应商？ | 「查到」/「推断」/「脑补」 |
| **替代来源** | 是否有第二个以上供应商？是否不同地域？ | 多源 → 散掉信号 |
| **技术路线替代** | 是否存在完全不同的技术路线可以绕过这个子件？ | 有替代 → 散掉信号 |
| **转换成本** | 换供应商的代价多大？是否需要重新验证/注册？ | 极高 → 卡点信号 |

> **来源标记说明：**
> - 「查到」— 有公开证据支持
> - 「推断」— 从已知信息合理推导
> - 「脑补」— 缺乏数据支撑，需进一步验证

### 收手裁决（Stopping Rule）

每层下钻后做判断——是继续往下钻，还是收手：

| 裁决 | 条件 | 含义 |
|------|------|------|
| **❌ 散掉了（Dispersed）** | 多源供应 + 可替代路线 + 转换成本可接受 | 这条支不构成共享卡点 |
| **✅ 找到了（Found）** | 单一/双寡头供应 + 无替代路线 + 转换成本极高 | 物理卡点确认 |
| **🟡 垂直封闭（Vertical）** | 各家自研配方，不共享供应商 | 不是共享卡点，但新进入者必须从头自研 |
| **⚠️ 正在消退（Fading）** | 曾是壁垒，但有国产替代或新技术正在突破 | 时间窗口内的卡点 |

收手后汇总所有支的判断：

```
支 1  → ❌ 散掉了（原因：...）
支 2  → ✅ 找到了 — [卡点名]
支 3  → 🟡 垂直封闭
支 4  → ❌ 散掉了

供应链小结：N 条支中，只有支 X 找到了真正的物理卡点。
```

> **但这就是最终结论吗？** 供应链分析的最大盲区在于：它只找"谁卖给谁、谁依赖谁"，但有些卡点不是供应商，而是物理定律和人体生理。于是需要下一步——

---

## Step 3: 第一性原理 Ground Truth 分解

### 方法论

**追问：什么根本约束是所有玩家都绕不开的？**

每一层追问都要找到**更根本的原因**——直到抵达物理、生物、制度、经济层面的第一性原理。

### 五类 Ground Truth

| 类型 | 追问方向 | 示例 |
|------|---------|------|
| **🌍 物理学** | 什么物理定律限制了性能天花板？ | 信号延迟、扩散速率、能量守恒 |
| **🧬 生物学** | 什么生物机制是人体/自然决定的？ | 异物反应、代谢途径、免疫排斥 |
| **⚗️ 化学** | 什么化学反应链构成了限速步？ | 催化效率、电子传递、材料降解 |
| **🏛️ 制度** | 什么法规/专利/标准是结构性的？ | 临床试验要求、专利丛林、审批周期 |
| **💰 经济学** | 什么成本结构决定了可触达市场？ | 日成本栅栏、规模效应、良率约束 |

### Ground Truth 判断标准

| 标准 | 说明 |
|------|------|
| **不可绕过性** | 是否换供应商/换技术路线都无法消除此约束？ |
| **普遍性** | 是否所有玩家（无论大小新旧）都同等承受此约束？ |
| **稳定性** | 此约束是否在可预见的未来不会消失？ |

### Ground Truth 识别模板

```
## Ground Truth N: [学科] — [核心约束]

### 根本事实
[用一两句话描述这个约束的本质]

### 它对行业意味着什么
1. [推论1：这个约束直接导致的行业特征]
2. [推论2：它限制了哪些可能性]
3. [推论3：它创造哪些商业机会]

### 推论清单
| 推论 | 影响 |
|------|------|
| [推论A] | [对行业格局的影响] |
| [推论B] | [对企业战略的影响] |

### 例外（证明规则的）
[如果存在例外情况，它说明了什么？绕行的代价是多少？]
```

## Step 4: 交叉效应 + 卡点重评估

### 交叉效应矩阵

Ground Truth **不是独立的**——它们互相放大。找到交叉效应是这套方法论最重要的产出之一。

```
                    ┌──────────────────┐
                    │   Ground Truth 1 │
                    │   [核心约束]      │
                    └───────┬──────────┘
                            │
              "推断：它对 GT2 的影响"
                            │
                            ▼
                    ┌──────────────────┐
        ┌───────────│   Ground Truth 4 │───────────┐
        │           │   [核心约束]      │           │
        │           └──────────────────┘           │
        │                    ▲                      │
  "GT1→GT4"                  │               "GT3→GT4"
        │                    │                      │
        ▼                    │                      ▼
┌──────────────────┐        │        ┌──────────────────┐
│  Ground Truth 3  │        │        │  Ground Truth 2  │
│  [核心约束]       │◄───────┼───────►│  [核心约束]       │
└───────┬──────────┘        │        └───────┬──────────┘
        │                   │                 │
   "GT3→GT2"       "GT4→GT5"          "GT2→GT5"
        │                   │                 │
        ▼                   ▼                 ▼
        └───────────────────┴─────────────────┘
                            │
                            ▼
                    ┌──────────────────┐
                    │  Ground Truth 5  │
                    │  [核心约束]       │
                    └──────────────────┘
```

## Step 5: 强制反证（Forced Falsification）

对每个判断的卡点，问一个**反证问题**来验证它的牢固性：

> **"如果这不是真卡点，世界应该是什么样？"**

### 反证模板

```
卡点候选：[卡点名称]

反证问题：如果 [卡点] 不是真卡点，那为什么 [行业领导者] 不 [做某件理论上可行的事]？

反证推演：
- 反证成立 → 卡点不牢固（可能只是历史偶然或商业选择）
- 反证不成立 → 卡点更牢固（因为有不可绕过的底层约束）

补充验证：是否已有玩家绕过/部分绕过了这个卡点？
- 如果有：绕行代价是多少？（成本/时间/性能损失）
- 如果没有：为什么？
```

## Step 6: "谁坐在卡点上"——公司映射

找到卡点后，分析**谁控制/拥有/坐在这个卡点上**。

| 卡点 | 持有方 | 持有方式 | 卡点可持续性 |
|------|-------|---------|:-----------:|
| [卡点A] | [公司/机构] | 专利/资源/技术/know-how/许可 | 高/中/低 |
| [卡点B] | [公司/机构] | ... | ... |

### 卡点持有方分类

| 类型 | 特征 | 示例 |
|------|------|------|
| **资源持有者** | 控制上游稀缺材料/矿产 | 锂/钴/稀土矿主，氦气供应 |
| **IP 持有者** | 持有核心专利/标准 | 专利基金会、标准组织 |
| **集成 know-how 持有者** | 拥有不可复制的工艺积累 | 自研配方、工艺参数、良率控制 |
| **制度持有者** | 拥有审批/准入/认证关系 | 临床数据、注册经验、审评关系 |
| **基础设施持有者** | 控制管道/电网/平台 | 电网接入、并网审批、操作系统 |

## 诚实分（Honesty Score）指南

每个卡点判断应附带诚实分，表示对该判断的置信度：

| 分数 | 含义 | 说明 |
|:----:|------|------|
| 🟢 8-10 | 科学文献/公开数据充分 | 有多个独立来源交叉验证 |
| 🟡 6-7 | 逻辑链条合理，但有缺口 | 部分推导基于推断，缺一手数据 |
| 🟡 4-5 | 逻辑成立但缺乏量化 | 方向正确，但无法量化壁垒高度 |
| 🟢 1-3 | 有线索但远未确认 | 基本是推测，需进一步验证 |

> **诚实分不是打分卡——它是让分析者对自己诚实的工具。** 低分不可怕，不说自己不知道才可怕。
