# 生物医药分析模板

> 当 `industry-analysis` 将行业类型判断为"生物医药/制药"时加载此模板。
> 适用场景：创新药、生物制剂、基因/细胞治疗、疫苗等以研发管线驱动的行业。

## 核心框架：管线驱动的金字塔

生物医药行业的核心价值不在当前营收，而在**研发管线**的深度和质量。

```
      💊 已获批（当前现金流）
     /  \
    /    \
   📋 Phase III（2-3年内获批）
  /  \
 /    \
🔬 Phase II / Phase I（中期价值）
 \
  \
   🧪 临床前/发现（远期价值）
```

**关键判断：** 管线阶段分布决定公司/行业的未来3-10年价值。管线越早期，不确定性越大。

## 管线分析框架

### 管线阶段评估

| 阶段 | 成功率 | 周期 | 成本 | 关键数据来源 |
|------|--------|------|------|-------------|
| **发现/先导** | ~0.01% | 3-5年 | $5-10M | 学术论文、专利 |
| **临床前** | ~10%→临床 | 1-3年 | $10-20M | 动物模型数据、毒理 |
| **Phase I** | ~60%→Phase II | 1-2年 | $10-30M | ClinicalTrials.gov |
| **Phase II** | ~30%→Phase III | 2-3年 | $30-100M | ClinicalTrials.gov + 发表 |
| **Phase III** | ~50-60%→获批 | 3-5年 | $100-500M | ClinicalTrials.gov + FDA |
| **NDA/BLA** | ~85-90%→获批 | 1-3年 | — | FDA/EMA公开文件 |
| **获批上市** | — | — | — | 销售数据、报销情况 |

> 成功率数据为行业平均。FIC（First-in-Class）药物成功率通常低于同类Me-too药物。

### 管线价值评估方法

```
管线价值 = Σ(各适应症的峰值销售 × 成功率调整 × 专利剩余年限折现)

rNPV（风险调整净现值）= Σ [p_i × 现金流_i / (1+r)^t]
  其中 p_i = 该阶段的累计成功率
       r = 折现率（通常12-15%）
```

**实用简化：** 对分析师而言，不用真的算rNPV，但要有"风险调整"的思维：
- Phase III药物：看30-50%的市场峰值即可（调整获批概率）
- Phase II药物：看成功后的市场机会×20-30%
- Phase I药物：定性地看靶点逻辑 vs 未满足需求

## 监管路径分析

### 主要监管机构

| 监管机构 | 地区 | 审批速度 | 特殊通道 |
|---------|------|---------|---------|
| **FDA** | 美国 | 标准10-12月；优先6-8月 | Breakthrough, Fast Track, RMAT, Accelerated Approval |
| **EMA** | 欧洲 | 标准~1年 | PRIME, Accelerated Assessment |
| **NMPA** | 中国 | 标准~1-2年 | 突破性治疗、优先审评 |

**关键信号：** 获得FDA Breakthrough/PRIME/RMAT认定 → 大概率加速 + 提高成功概率。

### 监管审批的前瞻信号

```
临床数据读出 → 申请Breakthrough认定 → IND/CTA → 关键试验启动
                ↓
            FDA沟通（End-of-Phase II meeting等）
                ↓
            NDA/BLA提交 → 专家委员会 → 获批
```

**超前指标：**
- 关键临床试验达到主要终点（最大的价值催化剂）
- FDA授予突破性疗法认定（意味着科学价值认可）
- 专家委员会投票结果（通常预示最终决定）
- 竞争对手同类药物获批→降低本品的监管风险

## 专利生命周期与独占期

| 阶段 | 年数 | 分析要点 |
|------|------|---------|
| 专利申请 → 获批 | 3-5年 | 专利覆盖范围、化合物专利 vs 制剂专利 vs 用途专利 |
| 专利保护期 | 20年从申请起 | 有效专利期 = 20年 - 研发时间（通常剩余7-12年） |
| 上市后独占期 | 5-12年 | NCE独占5年、Orphan Drug独占7年、生物制剂12年 |
| 专利到期 → 仿制药/生物类似药 | — | 专利悬崖——通常在到期后1年内失去80-90%市场份额 |

**专利分析的关键问题：**
- 核心化合物专利何时到期？（这是最有价值的专利）
- 是否有后续专利（制剂、用途、组合疗法）延长生命周期？
- 是否存在专利挑战（ANDA、IPR）？

## 稀缺性控制点

| 控制点 | 稀缺性 | 说明 |
|--------|-------|------|
| **🧬 靶点独占** | 🔴 极高 | 已验证的靶点+先发优势（不可逆的临床数据） |
| **📜 专利壁垒** | 🔴 极高 | 化合物专利是最强护城河 |
| **📊 临床数据所有权** | 🟡 中高 | 关键试验数据不可复制（但数据可被引用） |
| **🏭 生产制造能力** | 🟡 中 | 生物制剂/ADC/CGT的生产工艺复杂 |
| **📈 商业化渠道** | 🟡 中 | 销售团队+医保准入（尤其在中国） |
| **🔬 研发平台** | 🟢 降低中 | 平台本身不稀缺，平台产出才稀缺 |

## 超前指标方向

| 类别 | 具体指标示例 | 数据来源 |
|------|-------------|---------|
| **临床试验推进** | Phase II→Phase III、患者招募进度、关键数据读出时间 | ClinicalTrials.gov, 公司公告 |
| **监管信号** | Breakthrough认定、优先审评、专家委员会 | FDA/EMA公开文件 |
| **专利态势** | 核心专利授权、专利挑战、补充保护请求 | 专利数据库 |
| **资本信号** | 生物医药VC融资额、IPO数量、BD交易规模 | 行业报告 |
| **学术前沿** | 靶点发现论文、新型技术平台论文 | PubMed, Consensus |
| **竞争管线** | 同类靶点+适应症的管线数量、阶段分布 | ClinicalTrials.gov, ChEMBL |

### MCP 增强采集

生物医药行业是 MCP 工具价值最高的行业类型：

| MCP工具 | 采集内容 | 价值 |
|---------|---------|------|
| **ClinicalTrials.gov** | `search_trials(condition=X)` → 管线阶段分布、赞助商 | 🔴 核心 — 管线数据最权威来源 |
| **ChEMBL** | `target_search(gene=X)` + `get_mechanism(molecule=X)` | 🟡 辅助 — 理解药物机制 |
| **PubMed** | `search_articles(query=X)` | 🟡 辅助 — 临床结果和综述 |
| **Consensus** | `search(query=X)` | 🟢 补充 — 学术综合 |

**推荐工作流：**
1. ClinicalTrials.gov 搜索适应症/靶点 → 获得管线全景
2. ChEMBL 查询靶点详情 → 理解作用机制和已知活性化合物
3. PubMed/Consensus 交叉验证 → 确认关键文献

### 差异化分析

- **疗效 vs 安全性**：同类药物中，哪个的疗效/安全性profile更好？
- **给药方式**：口服 vs 注射 vs 皮下？方便性差异巨大
- **患者群体**：全人群 vs 生物标志物筛选？
- **定价策略**：高定价低渗透 vs 低定价广覆盖？

## 市场规模估算

生物医药市场估算需区分已商业化和未商业化药物：

### 已获批适应症
```
TAM = 患者人数 × 治疗率 × 年治疗费用
SAM = TAM × 渗透率（取决于竞争、安全性优势）
SOM = SAM × 可达份额（取决于商业化能力）
```

### 未获批管线
```
潜在市场 = 患者池 × 估计定价 × 成功概率调整
  └─ 成功概率 = 当前阶段到获批的累计成功率
  └─ 定价参考 = 同类已获批药物/对标市场
```

## MCP 增强数据采集（可选）

> 生物医药是 MCP 增强价值最高的行业类型。详见下文"数据采集策略"中的 MCP 增强采集部分。

**ClinicalTrials.gov 使用示例：**
```
search_trials(condition="colorectal cancer", intervention="PD-1 inhibitor", status="active")
  → 获得所有活跃的结直肠癌PD-1临床试验
  → 分析：试验数量趋势、Phase分布、主导赞助商
```

**ChEMBL 使用示例：**
```
target_search(gene_symbol="PDCD1")  → PD-1靶点详情
  + compound_search(name="pembrolizumab")  → Keytruda的靶点和机制
  + get_mechanism(molecule_chembl_id=...)  → 作用机制确认
```

**PubMed 使用示例：**
```
search_articles(query="PD-1 inhibitor colorectal cancer Phase III 2025")
  → 获取最新关键临床试验结果发表
```
