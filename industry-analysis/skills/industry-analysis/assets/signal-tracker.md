# Signal Tracker / 超前指标追踪

> 跨 session 追踪超前指标信号变化。每次分析完成后更新此文件。
> 每条指标维护最近 3 次的状态记录，形成趋势可见性。

---

## 使用方法

1. 完成行业分析后，将识别的超前指标追加到此文件
2. 每次复查时更新已有指标的信号方向和最新数值
3. 信号方向标记：
   - 🟢 **向上**：指标在向积极方向发展
   - 🔴 **向下**：指标在向消极方向发展
   - 🟡 **持平**：指标无显著变化
   - ⚪ **待确认**：尚无足够数据判断方向

---
